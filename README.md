# NLP Support Ticket Router — классификация обращений

Демонстрационный NLP-сервис для автоматической классификации русскоязычных обращений пользователей. Подходит как стартовая основа для интеграции в службу поддержки, CRM или Telegram-бота.

> **Статус:** учебно-демонстрационный AI-assisted проект. В комплекте небольшой **синтетический** датасет; модель не предназначена для production без обучения и проверки на реальных размеченных данных. Выходные оценки классификатора не следует считать калиброванной вероятностью.

## Возможности

- Определяет одну из пяти категорий: `technical`, `payments`, `delivery`, `refund`, `account`.
- Предоставляет REST API: `POST /classify`, `GET /categories` (FastAPI).
- Обучает простой воспроизводимый baseline: символьный TF-IDF + логистическая регрессия.
- Содержит проверку входных данных, оценку модели и автоматические тесты.
- Работает локально без ключей сторонних API.

## Установка и запуск

Нужен Python 3.10+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.api:app --reload
```

Документация API: http://127.0.0.1:8000/docs

Пример запроса:

```bash
curl -X POST http://127.0.0.1:8000/classify \
  -H 'Content-Type: application/json' \
  -d '{"text": "Не могу войти в личный кабинет"}'
```

Запуск через командную строку и тесты:

```bash
python -m app.cli "Курьер задерживается с доставкой"
python -m app.cli --evaluate
python -m pytest -q
```

## Устройство проекта

- `app/model.py` — ML-пайплайн и оценка качества;
- `app/api.py` — FastAPI и схемы данных;
- `app/cli.py` — запуск классификации из терминала;
- `data/tickets.csv` — синтетические тренировочные примеры;
- `tests/` — автоматические проверки;
- `.github/workflows/tests.yml` — CI.
